# /opsx:skip

Skip the current task or abort the entire change.

## Before doing anything

1. Read `.cursor/skills/openspec-skip/SKILL.md`.
2. Follow that skill as the source of truth.
3. Do not implement from this stub alone.

## Syntax

- `/opsx:skip <task-id>` — skip a specific task
- `/opsx:skip --task` — interactive task selection
- `/opsx:skip --change` — abort the current change
- `/opsx:skip --change <name>` — abort a specific change

See `.cursor/skills/openspec-skip/SKILL.md` for full implementation.
