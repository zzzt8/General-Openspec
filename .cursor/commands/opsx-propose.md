# /opsx-propose

Propose a new change with all artifacts generated in one step.

## Before doing anything

1. Read `.cursor/skills/openspec-propose/SKILL.md`.
2. Follow that skill as the source of truth.
3. Do not execute from this stub alone.
4. If the skill file cannot be read, stop and report the missing skill.

## Syntax

- `/opsx-propose <name>` — create a change with the given name
- `/opsx-propose` — interactive mode, will ask what you want to build
